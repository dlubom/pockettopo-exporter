# PocketTopo Exporter 1.0.0

The first stable offline command-line release for Windows, macOS and Linux,
with x64 and ARM64 downloads for each system. No Go, Python, Wine or PocketTopo
installation is required.

- Read and inspect supported PocketTopo TOP v3 files while preserving originals.
- Export Text, Therion interchange, DXF plan/side, VisualTopo, Toporobot, 3D DXF,
  Walls SRV and Survex SVX, with source identity and transformation/loss reports.
- Optionally install a per-user Windows right-click export menu for TOP files.
  In Windows 11, find it under **Show more options**.
- MIT license, quick-start instructions, package metadata and SHA-256 checksums.

Download the ZIP matching your computer, extract it and follow `QUICKSTART.md`.
Use program archives rather than the source-code ZIPs. Windows/macOS binaries
are unsigned; OS approval may be needed on first launch.

Supported profiles and resource limits are documented in `docs/CAPABILITIES.md`.
Therion output is native interchange, not a standalone Therion project; Walls
and Survex profiles are measurement-only. Older TOP versions are unsupported.
