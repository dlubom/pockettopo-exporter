# PocketTopo Exporter 1.0.1

Fixes [issue #2](https://github.com/dlubom/pockettopo-exporter/issues/2): export
`report.json` now records `tool_version: "1.0.1"`, matching `--version` and
inspection. Covers all eight export formats, including DXF plan and side.
Survey/drawing export bytes and other report fields are unchanged.

Downloads are available for Windows, macOS and Linux on x64 and ARM64.
